Classification Control Report

이미지 폴더를 선택하고 Classification 모델 A 또는 B로 분류한 뒤 결과 이미지를 폴더별로 저장하는 화면 설명서입니다.

Control: ClassifyControl Generated: 2026-05-31 Models: ClassifyModel_A / ClassifyModel_B

1. 목적

Classification 화면은 source folder 아래의 이미지 파일을 선택된 classification 모델로 분류하고, 모델명과 분류 결과에 따라 output folder에 이미지를 저장합니다. 분류 결과 이미지는 classification label이 표시된 annotated image로 저장됩니다.

결과는 source folder의 부모 폴더 아래 SourceFolderName_classified 폴더에 생성되며, 화면 하단 결과 리스트와 우측 Preview에서 확인할 수 있습니다.

2. 화면 구성

영역 주요 UI 역할
Classification Settings Source Folder, Browse 분류 대상 이미지 폴더를 선택합니다. 선택된 경로는 config에 저장됩니다.
Classification Model Selection ClassifyModel_A, ClassifyModel_B 분류에 사용할 모델을 RadioButton으로 선택합니다.
Model Path 각 모델별 Path TextBox, Browse 모델 A/B의 경로를 사용자가 직접 지정할 수 있습니다.
Model Load 각 모델별 Load Model, status label 모델 A/B를 독립적으로 명시 로드하고 Loaded/Not Loaded 상태를 표시합니다.
Execution Start 선택된 모델로 source folder의 이미지 분류를 시작합니다.
Progress ProgressBar, Log 처리 진행률과 분류 로그를 표시합니다.
Classification Results Category, Filename, Path ListView 분류 결과별 저장 이미지 목록을 표시합니다.
Image Preview PictureBox, preview info 결과 리스트에서 선택한 이미지를 미리보고 category, filename, size 정보를 표시합니다.

3. 모델 경로와 로드 흐름

  • ClassifyModel_A와 ClassifyModel_B는 각각 별도의 path, Browse, Load Model 버튼을 가집니다.
  • Browse로 경로를 선택하면 즉시 config에 저장됩니다.
  • Path TextBox를 직접 수정한 경우, 입력창에서 포커스가 빠질 때 자동 저장됩니다.
  • 각 Load Model 버튼은 해당 모델만 명시적으로 로드합니다.
  • Start 실행 시 선택된 모델이 로드되지 않았다면 자동으로 모델을 로드한 뒤 분류를 진행합니다.
  • 이미 같은 경로의 모델이 로드되어 있으면 다시 로드하지 않습니다.
  • 모델 로드 중에는 프로그램 창 중앙에 안내 popup이 표시되고, 완료되면 자동으로 닫힙니다.

4. 실행 흐름

  1. Source folder가 선택되어 있고 실제 존재하는지 확인합니다.
  2. 사용할 classification 모델을 RadioButton에서 확인합니다.
  3. 선택된 모델 path가 비어 있지 않고 실제 존재하는지 검증합니다.
  4. 선택된 모델이 로드되지 않았다면 popup을 띄우고 모델을 로드합니다.
  5. Source folder 아래의 이미지 파일을 재귀적으로 수집합니다.
  6. 각 이미지를 선택된 모델로 inference합니다.
  7. 분류 결과 label을 이미지 위에 표시한 annotated image를 생성합니다.
  8. Output folder 아래 {SelectedModel}/{ClassificationResult} 폴더에 저장합니다.
  9. 분류 결과 dictionary를 화면 결과 ListView에 표시합니다.

5. 분류 처리 규칙

항목 규칙
대상 이미지 확장자 .jpg, .jpeg, .png, .bmp
Output root SourceFolderName_classified
결과 폴더 구조 {OutputRoot}/{SelectedModel}/{ClassificationResult}/{RelativePath}
결과 key {SelectedModel}_{ClassificationResult}
Inference 오류 모델 실행 오류가 발생하면 결과 class를 ERROR로 처리합니다.

6. Annotated Image 표시

  • 저장되는 결과 이미지는 원본 이미지 위에 classification label을 표시한 이미지입니다.
  • Label text는 {ModelName}: {ClassificationResult} 형식입니다.
  • Classification result가 OK이면 초록색, NG이면 빨간색, 그 외 값은 파란색 텍스트로 표시됩니다.
  • 라벨 가독성을 위해 흰색 배경 사각형과 색상 테두리를 함께 그립니다.

7. 결과 표시와 Preview

  • 분류 완료 후 ListView에 category, filename, full path가 표시됩니다.
  • Category는 {SelectedModel}_{ClassificationResult} 형태입니다.
  • 결과 항목을 선택하면 저장된 annotated image를 Preview에 표시합니다.
  • Preview info에는 category, filename, image size, file size가 표시됩니다.

8. 저장되는 설정

설정 내용
LastClassifySourceFolder 마지막으로 선택한 classification source folder
DiceModels.ClassifyModel_A.Path Classification model A 경로
DiceModels.ClassifyModel_A.Use Classification model A 사용 여부
DiceModels.ClassifyModel_B.Path Classification model B 경로
DiceModels.ClassifyModel_B.Use Classification model B 사용 여부

9. 주의사항

  • 분류는 한 번에 선택된 모델 하나로만 수행됩니다.
  • 기존 output folder를 자동 삭제하지 않으므로 이전 결과 파일이 남아 있을 수 있습니다.
  • Output folder 구조는 모델명과 분류 결과명에 의존합니다.
  • Path TextBox의 자동 저장은 실제 존재하는 파일 또는 폴더 경로일 때만 수행됩니다.

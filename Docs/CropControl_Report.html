Image Crop Control Report

이미지 폴더를 선택해 Detection 기반 자동 크롭 또는 고정 좌표 수동 크롭을 수행하는 화면 설명서입니다.

Control: CropControl Generated: 2026-05-31 Modes: Auto Detect Crop / Manual Crop

1. 목적

Image Crop 화면은 선택한 source folder 아래의 이미지 파일을 대상으로 crop 이미지를 생성합니다. Auto Detect mode에서는 Detection 모델이 찾아낸 object rectangle을 기준으로 class별 crop 이미지를 저장하고, Manual Crop mode에서는 사용자가 입력한 고정 좌표와 크기를 모든 이미지에 적용합니다.

결과는 source folder의 부모 폴더 아래에 SourceFolderName_crop 폴더로 생성되며, 실행 후 결과 리스트에서 crop 이미지를 선택해 우측 Preview로 확인할 수 있습니다.

2. 화면 구성

영역 주요 UI 역할
Crop Settings Source Folder, Browse, Images Found 크롭 대상 이미지 폴더를 선택하고, 하위 폴더를 포함한 이미지 개수를 표시합니다.
Crop Mode Manual Crop (Disable Auto Detect) 체크 시 Detection 모델을 사용하지 않고, 사용자가 입력한 고정 crop 영역을 사용합니다.
Manual Area X, Y, W, H Manual Crop mode에서 사용할 좌상단 좌표와 crop 크기를 입력합니다.
Detection Model Model Path, Browse, Load Model, status label Auto Detect Crop에 사용할 Detection model path를 관리하고 명시적으로 모델을 로드합니다.
Execution Start Crop 선택한 모드에 따라 crop 처리를 시작합니다. Auto Detect mode에서는 모델이 필요하면 자동 로드합니다.
Crop Results 결과 ListBox, result count 생성된 crop 이미지 파일명을 표시합니다.
Preview PictureBox, preview info 선택한 crop 이미지와 파일 정보를 표시합니다. Auto Detect 결과인 경우 원본 기준 detection box도 함께 표시합니다.

3. 모델 경로와 로드 흐름

  • Detection model path는 Browse로 선택하면 즉시 config에 저장됩니다.
  • Path TextBox를 직접 수정한 경우, 입력창에서 포커스가 빠질 때 자동 저장됩니다.
  • Load Model 버튼은 Detection 모델을 명시적으로 로드합니다.
  • Start Crop은 Auto Detect mode에서만 Detection 모델을 확인합니다.
  • 이미 같은 경로의 모델이 로드되어 있으면 다시 로드하지 않고 crop을 진행합니다.
  • 모델 로드 중에는 프로그램 창 중앙에 안내 popup이 표시되고, 로드 완료 후 자동으로 닫힙니다.
Manual Crop mode에서는 Detection 모델이 필요하지 않으므로 모델 경로가 비어 있어도 수동 크롭을 실행할 수 있습니다.

4. 실행 흐름

  1. Source folder가 선택되어 있고 실제 존재하는지 확인합니다.
  2. Manual Crop mode 여부를 확인합니다.
  3. Manual mode라면 X/Y/W/H 값이 유효한지 검사하고 config에 저장합니다.
  4. Auto Detect mode라면 Detection model path를 검증하고 저장합니다.
  5. Auto Detect mode에서 모델이 아직 로드되지 않았다면 popup을 띄우고 모델을 로드합니다.
  6. 이미지 파일을 재귀적으로 수집합니다. 대상 확장자는 .jpg, .jpeg, .png, .bmp입니다.
  7. 선택된 모드에 따라 ProcessCropImages 또는 ProcessManualCropImages를 실행합니다.
  8. 작업 완료 후 output folder에서 crop 결과 파일을 다시 읽어 결과 리스트를 갱신합니다.

5. Auto Detect Crop 규칙

  • Detection 모델 추론 결과 중 confidence가 0.5 미만인 rect는 제외됩니다.
  • 각 detection rect는 이미지 bounds 안으로 조정된 뒤 crop됩니다.
  • Class별 폴더가 output folder 아래에 생성됩니다.
  • 저장 파일명은 {ClassName}_{OriginalFileName} 형태입니다.
  • 원본 source folder의 하위 폴더 구조는 class folder 아래에 유지됩니다.
입력 예 출력 예
Source/sub/image001.jpg, class BELT_TOP Source_crop/BELT_TOP/sub/BELT_TOP_image001.jpg

6. Manual Crop 규칙

  • 사용자가 입력한 X, Y, W, H 값을 모든 이미지에 적용합니다.
  • Crop 영역이 이미지 bounds를 벗어나면 가능한 영역으로 조정됩니다.
  • Width 또는 height가 0 이하가 되는 경우 해당 이미지는 저장하지 않습니다.
  • 결과는 output folder 아래 MANUAL 폴더에 저장됩니다.
  • 저장 파일명은 MANUAL_{OriginalFileName} 형태입니다.

7. Preview 동작

  • Crop Results 리스트에서 파일을 선택하면 crop 이미지를 Preview에 표시합니다.
  • Auto Detect mode에서 생성된 결과라면 crop 파일명에서 원본 파일명을 추정하고, 원본 이미지에 Detection box를 그려 표시합니다.
  • Preview 하단에는 파일명, 이미지 크기, 파일 크기가 표시됩니다.
  • 원본 이미지가 없거나 모델이 로드되지 않은 경우 Detection box overlay는 생략될 수 있습니다.

8. 저장되는 설정

설정 내용
LastCropSourceFolder 마지막으로 선택한 crop source folder
DefaultCropArea Manual Crop에서 사용한 X/Y/W/H 값
DiceModels.DetectModel.Path Auto Detect Crop에 사용할 Detection model path
DiceModels.DetectModel.Use Detection model 사용 여부

9. 주의사항

  • Output folder는 source folder의 부모 폴더 아래에 _crop postfix로 생성됩니다.
  • Auto Detect Crop은 Detection 모델이 필요하며, Manual Crop은 모델 없이 동작할 수 있습니다.
  • 기존 output folder를 자동 삭제하지 않기 때문에 이전 crop 결과가 함께 표시될 수 있습니다.
  • Auto Detect Preview의 원본 파일명 추정은 crop 파일명의 class prefix 구조에 의존합니다.

File Filtering Control Report

대상 폴더에서 조건에 맞는 폴더와 파일을 선별한 뒤, 허용된 파일을 출력 폴더로 복사하는 기능 설명서입니다.

Control: FilterControl Generated: 2026-05-30 Mode: Copy only

1. 목적

File Filtering 화면은 사용자가 선택한 Target Folder 전체를 탐색하고, 현재 선택된 Preset 조건에 맞는 폴더를 찾은 뒤, 각 폴더 안의 허용된 파일만 출력 폴더로 복사합니다. 복사 시 원본 폴더의 상대 경로 구조를 유지합니다.

이 기능은 특정 이름의 폴더만 모으거나, 특정 파일을 포함한 폴더만 가져오거나, 임시 파일/백업 파일/특정 확장자를 제외하고 필요한 파일 세트만 정리할 때 사용합니다.

2. 화면 구성

영역 주요 UI 역할
Filtering Settings Target Folder, Browse 필터링을 시작할 기준 폴더를 선택합니다. 선택된 폴더 경로는 설정에 저장됩니다.
Preset Tabs Preset 1, Preset 2, Preset 3 서로 다른 필터 조건 조합을 3개까지 보관하고 탭으로 전환합니다.
Folder Filtering Folder name include, File name include 어떤 폴더를 복사 대상 폴더로 삼을지 결정합니다.
File Filtering File name exclude, Extension exclude 선택된 폴더 안에서 어떤 파일을 실제 복사에서 제외할지 결정합니다.
Execution Options Output mode, postfix, custom folder, Open, Start Filtering 출력 위치를 결정하고 필터링 복사를 실행합니다.
Progress ProgressBar, Log 처리 진행률과 복사/제외/오류 로그를 표시합니다.

3. Preset과 필터 조건

각 Preset은 아래 4가지 조건과 enable/disable 체크 상태를 독립적으로 저장합니다. 값은 쉼표로 구분하며, 비교는 대소문자를 구분하지 않는 부분 문자열 방식입니다.

조건 분류 동작
Use folder name include filter Folder Filtering 체크 시 폴더 이름에 include keyword 중 하나라도 포함된 폴더만 대상 폴더가 됩니다. 체크 해제 또는 keyword가 비어 있으면 target root와 모든 하위 폴더가 대상이 됩니다.
Use file name include filter Folder Filtering 체크 시 폴더 안에 include keyword와 일치하는 파일명이 하나라도 있는 폴더만 유지합니다. 이 조건은 “해당 파일을 가진 폴더를 가져오기” 위한 폴더 선별 조건입니다.
Use file name exclude filter File Filtering 체크 시 복사 단계에서 파일명에 exclude keyword가 포함된 파일을 제외합니다. 예: _temp, backup
Use extension exclude filter File Filtering 체크 시 복사 단계에서 지정된 확장자의 파일을 제외합니다. 확장자는 점 없이 입력하며, 입력 시 점이 있어도 내부적으로 제거됩니다. 예: tmp, bak
File name include 조건은 폴더를 선별하는 조건이고, File name exclude 및 Extension exclude 조건은 실제 복사할 파일을 선별하는 조건입니다.

4. 출력 폴더 옵션

옵션 출력 위치 특징
Create next to target folder Target folder의 부모 폴더 아래에 TargetFolderName + postfix로 생성 기본 postfix는 _filtered입니다. 실행 전 같은 output 폴더가 있으면 삭제 후 새로 생성합니다.
Use selected output folder 사용자가 선택한 임의의 output folder 폴더가 없으면 복사 전에 생성합니다. 기존 폴더 내용은 전체 삭제하지 않지만, 동일한 파일명은 복사 시 덮어씁니다.

Open 버튼은 현재 계산된 output folder를 Windows Explorer에서 엽니다. 아직 생성되지 않은 폴더라면 안내 메시지를 표시합니다.

5. 실행 흐름

  1. Target folder가 선택되어 있고 실제 존재하는지 확인합니다.
  2. Output folder 경로를 계산하고, target folder와 동일한 경로인지 검사합니다.
  3. 사용자에게 target folder와 output folder를 보여주고 실행 확인을 받습니다.
  4. 현재 Preset, output 옵션, filter 값을 config에 저장합니다.
  5. Target root와 모든 하위 폴더를 수집합니다.
  6. Folder name include filter를 적용해 1차 대상 폴더를 고릅니다.
  7. File name include filter를 적용해 특정 파일명을 가진 폴더만 남깁니다.
  8. Output folder가 target 아래에 있는 경우, output folder 자신과 그 하위 폴더는 대상에서 제외합니다.
  9. 각 대상 폴더의 파일을 검사하고, file name exclude 및 extension exclude 조건에 걸리지 않는 파일만 복사합니다.
  10. 복사가 끝나면 output folder 아래의 빈 폴더를 정리합니다.

6. 복사 규칙

  • 폴더 검색은 target root를 포함하며, 하위 폴더는 재귀적으로 탐색합니다.
  • 각 대상 폴더에서 파일 복사는 해당 폴더 바로 아래 파일만 처리합니다.
  • 복사된 파일은 target folder 기준 상대 경로를 output folder 아래에 유지합니다.
  • 동일한 파일명이 output 위치에 있으면 File.Copy(..., true)로 덮어씁니다.
  • 조건 비교는 대소문자를 구분하지 않습니다.
  • 현재 실행 모드는 복사 전용이며, 삭제 모드는 UI와 실행 흐름에서 제거되어 있습니다.

7. 저장되는 설정

설정 내용
LastTargetFolder 마지막으로 선택한 target folder
OutputPostfix 자동 output folder 생성 시 붙일 postfix
LastOutputFolder 마지막으로 선택한 custom output folder
UseCustomOutputFolder custom output folder 사용 여부
ActiveProfileIndex 마지막으로 선택한 Preset 탭 번호
ConditionProfiles 3개 Preset의 keyword 목록과 각 filter enable 상태

8. 주의사항

  • Keyword 조건은 정규식이 아니라 단순 포함 검색입니다.
  • Comma-separated 입력에서 빈 항목은 무시됩니다.
  • Extension exclude는 .jpg처럼 점을 입력해도 내부적으로 jpg로 비교합니다.
  • 자동 output mode는 기존 output folder를 삭제한 뒤 다시 만들기 때문에, output 폴더 안에 보존할 파일이 있으면 custom output mode를 사용하는 편이 안전합니다.
  • Custom output mode에서는 기존 폴더 전체를 삭제하지 않으므로 이전 결과 파일이 남아 있을 수 있습니다.

Label Generate Control Report

Detection 모델을 이용해 이미지별 rectangle label JSON을 생성하고, 결과를 Preview로 검토하는 기능 설명서입니다.

Control: LabelGeneratorControl Generated: 2026-05-30 Model: Detection

1. 목적

Label Generate 화면은 사용자가 선택한 source folder 아래의 이미지 파일을 재귀적으로 찾고, Detection 모델 추론 결과를 Labeler 형식의 JSON 파일로 저장합니다. 생성된 JSON은 원본 이미지와 같은 폴더에 같은 파일명으로 저장되며 확장자만 .json으로 바뀝니다.

생성 후에는 결과 목록에서 이미지 또는 JSON을 선택해 우측 Preview에서 이미지와 rectangle label을 확인할 수 있습니다.

2. 화면 구성

영역 주요 UI 역할
Label Gen Settings Source Folder, Browse label을 생성할 이미지 폴더를 선택합니다. 하위 폴더까지 재귀적으로 처리합니다.
Label Gen Settings Minimum Confidence (0~1) Detection confidence가 이 값보다 낮은 rect는 JSON 생성과 Preview 표시에서 제외합니다.
Label Gen Settings Existing JSON File Skip 체크 시 같은 이름의 JSON이 이미 존재하는 이미지는 label 생성을 건너뜁니다.
Detection Model Detection Model Path, Browse, Load Model Detection 모델 경로를 선택하고, 필요하면 명시적으로 모델을 로드합니다.
Execution Label Generate 모델이 로드되지 않은 상태면 자동으로 로드한 뒤 label 생성을 시작합니다.
Generate Results Image mode, JSON mode, 결과 ListView 이미지 목록 또는 JSON 목록을 표시하고, 선택한 항목을 Preview로 보여줍니다.
Image Preview PictureBox, Preview info label 이미지와 rect overlay, 파일명, 이미지 크기, detection/label 수를 표시합니다.

3. 모델 로드 흐름

  • Detection 모델은 프로그램 시작 시 즉시 로드하지 않고, Label Generate 화면에서 필요할 때 lazy-load합니다.
  • Load Model 버튼을 누르면 사용자가 선택한 model path를 저장하고 Detection 모델을 로드합니다.
  • Label Generate 실행 시 모델이 아직 로드되지 않았다면 자동으로 모델을 로드한 뒤 작업을 이어갑니다.
  • 모델 로드 중에는 안내 popup이 프로그램 창 중앙에 표시되고, 로드가 완료되면 자동으로 닫힙니다.
  • 모델 상태는 Loaded 또는 Not Loaded로 표시됩니다.

4. 실행 흐름

  1. Source folder가 선택되어 있고 실제 존재하는지 확인합니다.
  2. Detection model path가 비어 있지 않고 실제 존재하는지 확인합니다.
  3. Minimum Confidence, Existing JSON File Skip, model path 설정을 config에 저장합니다.
  4. Detection 모델이 로드되지 않았다면 popup을 표시하고 모델을 로드합니다.
  5. Source folder 아래의 .jpg, .jpeg, .png, .bmp 파일을 재귀적으로 수집합니다.
  6. 각 이미지에 대해 Detection inference를 수행합니다.
  7. 유효한 rect만 Labeler JSON 형식으로 변환합니다.
  8. 이미지와 같은 폴더에 같은 base name의 .json 파일을 저장합니다.
  9. 작업 완료 후 결과 목록을 다시 불러오고 로그와 progress bar를 갱신합니다.

5. JSON 생성 규칙

각 이미지의 출력 파일은 Path.ChangeExtension(imagePath, ".json") 방식으로 결정됩니다.

항목 생성 규칙
대상 이미지 확장자 .jpg, .jpeg, .png, .bmp
기존 JSON 처리 Existing JSON File Skip 체크 시 기존 JSON이 있으면 해당 이미지는 건너뜁니다. 체크 해제 시 새 JSON으로 덮어씁니다.
Confidence filter rect confidence가 Minimum Confidence보다 낮으면 제외합니다.
Bounds filter rect가 이미지 영역 밖으로 나가면 제외합니다.
Size filter rect width 또는 height가 0 이하이면 제외합니다.

JSON 구조 예시

{
  "version": "0.10.7",
  "task_type": "det",
  "shapes": [
    {
      "label": "class_name",
      "points": [[x1, y1], [x2, y2]],
      "group_id": null,
      "shape_type": "rectangle",
      "flags": {}
    }
  ],
  "split": "train",
  "imageHeight": 1024,
  "imageWidth": 1280,
  "imageDepth": 3
}

6. Generate Results와 Preview

표시 모드 목록 대상 Preview 동작
Image + Detection Display Results Source folder 아래의 이미지 파일 선택한 이미지에 대해 Detection을 다시 수행하고, confidence 기준을 통과한 rect를 이미지 위에 표시합니다. Detection model이 로드되지 않았다면 Preview 전에 자동 로드 popup이 표시됩니다.
Label + JSON Parsing Display Source folder 아래의 JSON 파일 JSON을 읽고 같은 폴더에서 같은 base name의 이미지 파일을 찾은 뒤, JSON의 rectangle points를 이미지 위에 표시합니다.

Class별 Rect 색상

Rect와 label text 색상은 class 이름 기준으로 생성됩니다. 같은 class는 항상 같은 색상으로 표시되고, 색상 범위는 초록색에서 파란색 계열로 제한되어 있습니다.

7. 저장되는 설정

설정 내용
LastLabelGenSourceFolder 마지막으로 선택한 source folder
LabelGeneration.MinConfidence Detection 결과를 JSON으로 저장할 최소 confidence
LabelGeneration.SkipExistingJson 기존 JSON 파일이 있을 때 건너뛸지 여부
DiceModels.DetectModel.Path Detection 모델 경로
DiceModels.DetectModel.Use Detection 모델 사용 여부

8. 주의사항

  • Label JSON은 별도 output folder가 아니라 원본 이미지와 같은 폴더에 생성됩니다.
  • Image preview 모드는 기존 JSON을 읽지 않고 Detection을 다시 수행해서 표시합니다.
  • JSON preview 모드는 모델 없이도 저장된 JSON을 기준으로 rect를 표시할 수 있습니다.
  • JSON preview에서 매칭 이미지는 같은 폴더, 같은 파일명, 확장자 .jpg, .jpeg, .png, .bmp 순서로 찾습니다.
  • Detection 결과가 없거나 유효한 rect가 하나도 없으면 JSON을 생성하지 않습니다.
